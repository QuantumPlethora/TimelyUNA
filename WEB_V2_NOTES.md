# TimelyUNA Web v2.0

This branch redesigns the public website around the central thesis:

> We do not see the universe as it is. We see it as its light arrives.

## Included

- Papyrus-first visual identity
- Dawn-first introduction
- Accessible speech narration through the browser Speech Synthesis API
- Apparent Now vs. Actual Position interaction
- SpaceTime Offset explanation
- Interactive Mars Lightline and communication-delay slider
- Mission-critical autonomy framing
- Craig's black-hole line with scientific reveal
- Interactive stellar-evolution stages
- Planck-length and Planck-time explorer
- TimelyUNA Lexicon: SpaceTime, Light-SpaceTime, Lightline, Photon Stamp, Apparent Now, Actual Position, SpaceTime Offset, Arrival History, Arrival Window, Reality Window, and Deep SpaceTime
- Responsive layout, semantic structure, keyboard-accessible controls, reduced-motion support, and no external JavaScript dependencies

## Scientific boundaries

The website describes the Sun, Mars, stellar evolution, black holes, and the Planck scale as educational demonstrations. Precision AR or navigation features should use trusted ephemerides and appropriate scientific libraries.
