The TimelyUNA vocabulary

Visible Now. Actual Now. SpaceTime Offset.

Visible Now
The position indicated by light arriving now—where you look based on photons in your eyes.
Actual Now
The modeled position after correcting for light travel—where the object is calculated to be at this moment.
SpaceTime Offset
The difference between those positions: the gap opened by finite light speed across Light-SpaceTime.

Visible Now answers: “Where do I look?” Actual Now answers: “Where is it modeled to be at this moment?” The difference is the SpaceTime Offset.
